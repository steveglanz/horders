# Hero select: the level-8 ability option, said plainly (25 Nov)

Steve: "The characters have something under them when you're selecting (muster level 8) and I don't even know what
that is." It was a disabled button under the class row reading "Muster · Lv 8": the selected class's ability option
(ALT_ABILITIES in sim/content/classes.ts), which swaps one action-bar slot from character level 8. Below level 8 it is
now a plain line, "Level 8: swap Anvil Skin for Muster" (the slot it replaces, and the option), not a button. From
level 8 the two swap buttons are unchanged.
