# Horders vision v2 (27 Nov 2026): how the 1.0 plan was made

Steve (27 Nov 2026) asked for a much deeper 1.0 plan: cohesion, a hook, replay value, nothing off the table. A design team of Claude agents worked in rounds. The plan of record that came out of it is in [../roadmap.md](../roadmap.md), section "1.0: the road to launch (plan of record, vision v2)"; where it differs from the files here, the roadmap wins.

| File | What it is |
|---|---|
| [research-retention.md](research-retention.md) | What keeps long-lasting action, roguelite and dungeon games alive (hooks, loops, replay value, retention), with sources |
| [research-market.md](research-market.md) | Top-rated mobile games, how players react to AI-made content, cohesive looks on a small budget, monetization models that rate well, with sources |
| proposal-*.md | Five role proposals: creative director, systems and retention, combat and feel, art director, mobile product |
| debate-*.md | Each role's reply after reading all five proposals |
| [vision.md](vision.md) | The game director's synthesis: pitch, pillars, world, loops, replay, combat, art, money, checkpoints with tasks by team, decisions, rulings on 20 disagreements |
| [redteam.md](redteam.md) | An outside producer's attack on vision.md and the 10 fixes, applied in the roadmap |

Changes the roadmap makes to vision.md: a grey-box fun test becomes Checkpoint 2 (before final art), with an animated look test judged by fresh players; first content is smaller (8 Sparks per class, 4 Relics); interrupts stay on some classes (Steve, 25 Nov); tiers stay capped at 15 (Steve, 26 Nov); the Hoard raid with bots joins launch if on time; one save wipe instead of a converter; the daily leaderboard is checked by replaying runs; a flat debug renderer stays for QA; honest AI wording (Claude writes the text, Steve approves it; no AI art or music); music is Steve's call; a plan for getting players.
